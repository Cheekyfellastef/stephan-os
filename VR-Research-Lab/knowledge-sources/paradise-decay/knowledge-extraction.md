# Paradise Decay VR Field Evidence

Status date: 2026-07-31  
Priority: P1  
Evidence class: creator demonstration and operational field telemetry

## Why this source matters

Paradise Decay has a large game-by-game catalogue of flat-to-VR and native-VR demonstrations. The value is not ownership of an injector or a conversion framework. The value is repeated physical-headset testing across games, profiles, runtimes and hardware.

This can help the VR Lab discover:

- games and engines worth investigating;
- working UEVR, vorpX and ReShade routes;
- profile sources and setup dependencies;
- first-person, room-scale and motion-control configurations;
- visual, comfort, performance and usability problems;
- failures that appear only after menus, cutscenes or longer play;
- hardware-specific differences between Quest 3, Pimax and other PCVR setups.

## Seed contributions

The public UEVR startup guide points users toward:

- Praydog UEVR releases;
- the community profile catalogue;
- Flat2VR community knowledge;
- Rai Pal for installed-library and engine discovery;
- practical startup warnings and setup sequencing.

The wider channel and Steam indexes contain repeated examples of:

- converting third-person games into first-person VR;
- enabling 6DoF motion controls and room scale;
- identifying titles that work well with only a profile;
- identifying titles requiring extra profile or mod work;
- comparing high-end and mainstream headset behaviour;
- judging whether an experience is merely stereoscopic, comfortably seated or convincingly native-feeling.

## Intake method

For each relevant video, create a compact record containing:

- title, canonical URL and publication date;
- game, engine and game build when known;
- headset, GPU, runtime and connection method;
- conversion tool, backend and profile identity;
- important settings and extra files;
- claimed working capabilities;
- visible or reported failures;
- play duration and tested scenarios when available;
- transcript/caption timestamps supporting material claims;
- confidence and reproduction status.

Public captions or transcripts may be used for search and attribution when available. Full transcripts and long verbatim passages must not be copied into the lab.

## Capability Graph candidates

- field-tested profile compatibility;
- headset-specific usability;
- first-person conversion viability;
- room-scale and 6DoF motion-control viability;
- cutscene and menu failure modes;
- comfort and frame-pacing observations;
- practical startup and runtime-switching sequences;
- ReShade SBS as a low-complexity stereo fallback;
- discovery of upstream tools and profiles.

## Trust boundary

A successful video demonstration proves that a configuration worked for that creator under the shown or described conditions. It does not prove:

- compatibility with Stephan's exact game build;
- long-duration stability;
- licence permission for underlying files;
- that the setup is reproducible without omitted steps;
- that source code implements a claimed technique in a particular way.

Battle Bridge reproduction and exact installed-build evidence remain required before promoting a setup to accepted local knowledge.

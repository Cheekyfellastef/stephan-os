# Starfield VR Reference Lab

This source pack is the Starfield-focused decision layer over the existing Stephanos VR Research Lab. It does not create a second VR programme or a second source of runtime truth.

## Canonical catalogue

The machine-readable catalogue lives at:

`shared/vr/starfieldVrReferenceCatalogue.mjs`

The operator workspace that renders it lives at:

`apps/starfield-vr-reference-lab/`

The catalogue maps each reference system to:

- the behaviour worth learning from;
- the closest Starfield attachment points;
- measurable VR acceptance tests;
- source and licence/reuse posture;
- the evidence class that prevents inspiration being mistaken for implementation proof.

## Reference stack

| Reference system | Primary lesson | Evidence posture |
|---|---|---|
| Starfield + Creation Kit | Universe, ships, quests and supported authoring | Proprietary foundation and official documentation |
| Mutar / NoMoreFlat `starfield2vr` | Existing Starfield-specific VR implementation | Pinned open implementation source |
| Skyrim VR + VRIK / HIGGS / PLANCK | Embodied open-world parity | Native VR and mod-specific evidence |
| Fallout 4 VR | Creation Engine firearms, utilities, looting and crafting | Behavioural reference |
| Half-Life: Alyx | Hand and object interaction | Behavioural reference |
| Lone Echo / Echo VR | Zero-gravity locomotion | Behavioural reference |
| No Man's Sky VR | Exploration and ship continuity | Behavioural reference |
| Elite Dangerous | Cockpit presence and space scale | Behavioural reference |
| Into the Radius | Physical loadout and inventory | Behavioural reference |
| Blade & Sorcery | Physics-driven bodily combat | Behavioural reference |
| Cyberpunk 2077 | Lighting and information-density language | Visual-principles reference |

Existing detailed source packs remain authoritative for the Starfield Creation Kit, Mutar / NoMoreFlat and the Skyrim VR ecosystem. The Reference Lab links to them through each catalogue entry rather than copying their pinned version claims.

## Promotion boundary

A reference becomes a Starfield VR capability candidate only after it has:

1. a separately authored, licence-compatible implementation proposal;
2. exact installed Starfield and dependency identities;
3. a reversible experiment that cannot damage the stable baseline or saves;
4. repeatable Battle Bridge evidence;
5. Quest 3 comfort, interaction and frame-time acceptance evidence.

Until all five exist, the Reference Lab reports design potential only.

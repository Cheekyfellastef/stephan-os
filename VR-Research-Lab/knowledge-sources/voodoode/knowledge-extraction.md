# VoodooDE VR Field Evidence

Status date: 2026-07-31  
Priority: P1  
Evidence class: creator demonstration, tutorial and operational evaluation

## Useful discovery

VoodooDE has showcased two distinct automation layers that should not be conflated:

### PCVR Mods Installer Hub

This is a cross-engine catalogue, installer and launcher for **existing** VR mods. It does not generate a new VR conversion from an unsupported game. Its value is discovering supported games, resolving installation routes and reducing setup friction.

### Unreal Easy Injector

This is a user-friendly management layer around UEVR for Unreal Engine games. It does not replace UEVR's conversion engine. It improves game discovery, backend selection, profile installation, profile editing, runtime switching, updates and in-headset operation.

## Field evidence to extract

VoodooDE videos can contribute:

- beginner setup sequences and points of confusion;
- headset and runtime configuration;
- graphics and upscaler compatibility observations;
- false-positive antivirus warnings around injection tools;
- game-profile installation and launch flow;
- comparison between a tool's marketing promise and actual steps;
- headset-specific quality and performance observations;
- demonstrations of supported games and motion-control capabilities.

## Video evidence policy

Use public captions, transcripts, descriptions and chapter markers when available. Record:

- canonical video ID and date;
- tool/release tested;
- game, headset, GPU and runtime when stated;
- steps and settings demonstrated;
- successful capabilities;
- caveats, failures and warnings;
- timestamps for material claims;
- whether the claim was independently verified from source or Battle Bridge evidence.

Do not store full transcripts or treat a demonstration as proof of how the code works internally.

## Starfield relevance

PCVR Mods Installer Hub currently lists Starfield VR, making it useful as an external discovery and installation reference. It must not replace the canonical Mutar source, exact build identity or Battle Bridge proof. Unreal Easy Injector is Unreal-specific and therefore not a Starfield conversion route, but its profile, backend and user-experience architecture is reusable inspiration for Stephanos' own no-click VR launcher.

# VR Knowledge Ingestion Roadmap

Priority ingestion sources:

1. UEVR ecosystem
2. REFramework
3. Thunderstore discovery index
4. OpenXR SDK and samples
5. OpenVR / SteamVR SDK
6. BepInEx ecosystem
7. MelonLoader ecosystem
8. Unity XR Interaction Toolkit examples
9. Nexus Mods metadata index
10. ModDB metadata index
11. Canonical game-specific VR projects
12. Local private reference packages (MutaR, Luke Ross, VorpX where licensed)

For every source:
- capture provenance
- verify licence
- pin version/commit
- classify engine
- extract reusable rendering, input, UI, tracking and interaction patterns
- avoid committing proprietary binaries

The host executes the canonical governor's read-only ObserveAdmission action. The existing watcher remains the sole state and model writer. Perform SELECTED, CLAIMED, PHYSICAL_PICKUP, EDITED, TESTED and ISOLATED_COMMIT as separate correlated receipts. Check the actual changed path and bytes, preserve the Node output and its hash, and read back a clean exact-parent commit. A command acknowledgement, claim or healthy endpoint alone is not construction.

### Stops and integration

Retain failed claims, worktrees, test logs, commits and interrupted publication evidence for the same owner's explicit reconciliation. Do not automatically delete, retry, replace or reassign them. A source commit still requires independent review and protected integration. Live execution requires its own fresh exact consent.

This mode assumes a trusted operator and cooperative workers and provides less assurance than full containment. Hostile-writer containment, independent worker commissioning, Island 02 and unattended refill remain separate unproven milestones.

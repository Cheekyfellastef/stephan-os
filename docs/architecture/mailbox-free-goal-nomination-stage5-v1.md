## What this source-only stage adds

A deterministic, testable **read-only nomination projector**. It accepts independently fetched origin and readback workflow run metadata, the current main SHA and original issue, the one exact Stage 4 artifact metadata and downloaded ZIP bytes. The projector validates:

- Canonical repository and numeric owner identity, fixed workflow names/IDs/paths, first attempts, genuine workflow_dispatch to workflow_run relationship, timestamps, source main, successful completion, bounded freshness.
- One exact artifact whose run, source, fixed name, SHA-256, size, repository and expiry match. Its ZIP is parsed entirely in memory, rejects extra entries, path traversal, unbounded deflation, invalid CRC, invalid local/central metadata and unknown proof fields.
- The Stage 4 source proof kind, original issue ID, current goal still open, immutable exact source, original Stage 1 artifact identity and **all seven explicit false authority flags**.

Even on a positive matched packet, the output is DISCOVERY_ONLY_NOT_ADMITTED with schedulerEligible=false, originalGoalAdmissionGranted=false, exclusiveClaimGranted=false, executionAuthorized=false, sourceMutationAllowed=false, protectedMergeAllowed=false, nativePickupProven=false, independentlyAuthenticatedNativeCustody=false and independentlyAuthenticatedTransport=false.

The output is **not** a canonical mission, job, queue item or source-grant object. An actor cannot put an unverified metadata packet directly into the native Mission Worker by calling the projector.

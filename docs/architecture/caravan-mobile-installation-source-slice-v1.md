## Reusable invariant

Use one canonical request/WAL/Job across source preparation, device approval, execution, cancellation and reconciliation. Preserve uncertainty until physical evidence resolves it. Source integrity, authenticated release eligibility, approval consumption, process start, installed bytes and later boot are distinct facts. Transport failure never creates a new authority owner, request, source change or proof.

After root exit, observe the whole native Job through the existing bounded drain budget. A transient live member does not prove terminal failure; only real zero proves drainage, and a persistent member at the deadline still fails closed. Neither a sleep nor child success text substitutes for native accounting.

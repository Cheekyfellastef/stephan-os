## Exact progression

1. **Source identity.** Canonical repository, PR, branch, distinct 40-character HEAD/base. A supplied pair remains reported and unattested until trusted GitHub readback.
2. **Physical model observation.** Sanitized Sovereign Commander observation must match exact source and contain a loaded Ollama model and GPU. Names, VRAM usage and successful localhost HTTP are not model digest, host principal or gaming-governor evidence.
3. **Windows 13-case calibration.** Recognizes only a bound, complete 13/13 Windows remote projection with 64-character manifest/observation/model-digest fields and every authority flag false. It remains CANDIDATE_UNATTESTED pending fixed installed-parent authentication.
4. **Ten baseline plus five privileged challenges.** Recognizes the existing localReviewCapabilityExamV1 result shape, 15/15 completion and zero missing or failed cases, but cannot authenticate the caller-provided auditor trust pin. It remains EXAM_REPORTED_UNATTESTED.
5. **Independent commissioning and admission.** Always HELD in this module. Out-of-band protected Windows principals, witness and auditor signing roots, revocation/non-replay, independently reviewed provider-neutral specialist admission and protected operator merge approval remain mandatory.

## How it is used

Call assessSovereignReviewerQualificationLadderV1 with the exact source identity, already-acquired sanitized Commander observation, fixed Windows calibration projection, and existing signed capability-exam result. It returns five machine-readable rungs, one next action and immutable false authority flags. No arbitrary shell, model invocation, file access, GitHub write, signer, source mutation or lease action is performed.

The returned evidenceProvenance is always UNTRUSTED_INPUT_CANDIDATE_ONLY. Even perfectly shaped 13/13 and 15/15 caller-supplied results do not establish a qualified specialist. Missing/stale/mismatched data, getters, cyclic payloads, oversized arrays and spoofed admission flags remain held.

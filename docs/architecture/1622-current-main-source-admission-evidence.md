# Evidence chain

Protected main is the canonical source revision. `readAuthoritativeProgrammeProjection` derives `machineryInventory.sourceHead` from the canonical repository checkout. The higher-level elastic dispatcher already uses that authoritative source head. The remaining legacy seam in `ensureCriticalBacklogMission` still derives its initial elastic source revision from `STEPHANOS_MISSION_WORKER_HEAD_SHA`, which is a physical worker launch identity and can lag after main advances.

That coupling is the regression target in this lane.

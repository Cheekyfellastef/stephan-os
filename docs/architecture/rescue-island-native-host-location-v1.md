# Rescue Island: restore the existing native host in its generated estate

Goal #3103 — Rescue Island: two independent proof-gated builders outside Goal Conveyor.

The already approved cooperative host is preserved, not lost. Its seven files
remain under the original installation checkpoint and match the retained native
build manifest. Returning them to `src/windows/Stephanos.RescueIslandHost/bin`
conflicts with the canonical source-proof classifier. Broadly exempting native
build directories would weaken source truth.

The bounded correction uses one shared production location:
`.stephanos/local-state-checkpoints/rescue-island-native-host/bin/Release/net8.0-windows/`.
That generated estate is already recognized by source proof. Its six directory
components preserve the unchanged native executable's canonical-root resolution.
The original `src/windows/.../bin` remains a build/test output, not the deployed
production path. No native source, binary, service, principal or signer changes.

Both existing supervised adapters must derive that same fixed path. Before
using it they must verify the exact seven approved artifact identities and
current native source inputs, with bounded physical/no-redirect file reads.
Missing, changed, unexpected or ambiguous files hold execution. A caller cannot
select the production path or supply its own trusted artifact manifest.

Restoration and execution remain separate. This source proposal does not copy
or launch an executable, enroll a worker, release custody, consume Seed consent,
or grant merge/restart authority. After independently reviewed protected source
integration, restoration retains the original checkpoint and verifies the exact
bytes at the fixed destination. A real task still needs fresh exact owner
consent, complete canonical/Seed/Island claims and original serial CPU/gaming
admission. Historical Island outputs and the retained Seed task are unchanged.

Qualification covers fixed shared path/root depth, unchanged source classification,
strict artifact and source identity, missing/tampered/extra/redirected files,
and both existing adapter paths. Fixtures are not live pickup evidence.

Invariant: generated native host placement is a replaceable platform adapter
derived from canonical source, not a reason to weaken source proof or duplicate
the worker/authority model.
